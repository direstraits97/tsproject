## Om webbplatsen
Denna uppgift har gått ut på att skapa en webbplats med ramverket Angular för ett fiktivt lärosäte där användaren ska kunna:
- Se de kurser som erbjuds.
- Filtrera dessa baserat på ämneskategori samt kurskod och kursnamn.
- Se antal resultat baserat på filtrering.
- Sortera kurserna baserat på kursnamn, kurskod, poäng och ämne.
- Lägga till önskade kurser i ett eget ramschema utan möjlighet till dubbletter.
- Ta bort sparade kurser.

Utöver dessa funktioner har jag även implementerat paginering samt en startsida för lärosätet.
